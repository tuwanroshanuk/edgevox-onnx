# Introduction

- [./EdgevoxOnnxHar](./EdgevoxOnnxHar) It is for building `edgevox_onnx.har`.
  If you don't need to change the C++ or Typescript code of edgevox-onnx, then
  you can download pre-built `edgevox_onnx.har` from us. Just run `ohpm install edgevox_onnx`.
  Please refer to our [doc](https://k2-fsa.github.io/sherpa/onnx/harmony-os/how-to-build-har.html)
  if you want to build `edgevox-onnx` from source.

- [./EdgevoxOnnxSpeakerDiarization](./EdgevoxOnnxSpeakerDiarization) It shows how
  to run on-device speaker diarization.

- [./EdgevoxOnnxSpeakerIdentification](./EdgevoxOnnxSpeakerIdentification) It shows how to use
  speaker embedding models for on-device speaker identification.

- [./EdgevoxOnnxStreamingAsr](./EdgevoxOnnxStreamingAsr) It shows how to use
  streaming ASR models for real-time on-device speech recognition.

- [./EdgevoxOnnxTts](./EdgevoxOnnxTts) It shows how to run on-device text-to-speech.
  Please see the doc at <https://k2-fsa.github.io/sherpa/onnx/harmony-os/tts.html>

- [./EdgevoxOnnxVadAsr](./EdgevoxOnnxVadAsr) It shows how to use
  VAD + Non-streaming ASR for speech recognition.
  Please see the doc at <https://k2-fsa.github.io/sherpa/onnx/harmony-os/vad-asr.html>
