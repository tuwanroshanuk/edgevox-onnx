# Introduction

Please refer to
https://k2-fsa.github.io/sherpa/onnx/android/index.html
for usage.

|Folder| Pre-built APK | Description|
|------|---------------|-------------|
|[EdgevoxOnnxSpeakerDiarization](./EdgevoxOnnxSpeakerDiarization)| | It is for speaker diarization.|
|[EdgevoxOnnx](./EdgevoxOnnx)| [URL](https://k2-fsa.github.io/sherpa/onnx/android/apk.html)| It uses a streaming ASR model.|
|[EdgevoxOnnx2Pass](./EdgevoxOnnx2Pass)|[URL](https://k2-fsa.github.io/sherpa/onnx/android/apk-2pass.html)| It uses a streaming ASR model for the first pass and use a non-streaming ASR model for the second pass|
|[EdgevoxOnnxKws](./EdgevoxOnnxKws)|[URL](https://k2-fsa.github.io/sherpa/onnx/kws/apk.html)| It demonstrates how to use keyword spotting|
|[EdgevoxOnnxSpeakerIdentification](./EdgevoxOnnxSpeakerIdentification)|[URL](https://k2-fsa.github.io/sherpa/onnx/speaker-identification/apk.html)| It demonstrates how to use speaker identification|
|[EdgevoxOnnxTts](./EdgevoxOnnxTts)|[URL](https://k2-fsa.github.io/sherpa/onnx/tts/apk.html)| It is for standalone text-to-speech.|
|[EdgevoxOnnxTtsEngine](./EdgevoxOnnxTtsEngine)|[URL](https://k2-fsa.github.io/sherpa/onnx/tts/apk-engine.html)| It is for text-to-speech engine; you can use it to replace the system TTS engine, e.g., use it in a e-book reader app|
|[EdgevoxOnnxVad](./EdgevoxOnnxVad)|[URL](https://k2-fsa.github.io/sherpa/onnx/vad/apk.html)| It demonstrates how to use a VAD|
|[EdgevoxOnnxVadAsr](./EdgevoxOnnxVadAsr)|[URL](https://k2-fsa.github.io/sherpa/onnx/vad/apk-asr.html)| It uses a VAD with a non-streaming ASR model.|
|[EdgevoxOnnxWebSocket](./EdgevoxOnnxWebSocket)| |It shows how to write a websocket client for the [Python streaming websocket server](https://github.com/k2-fsa/edgevox-onnx/blob/master/python-api-examples/streaming_server.py).|
|[EdgevoxOnnxAudioTagging](./EdgevoxOnnxAudioTagging)|[URL](https://k2-fsa.github.io/sherpa/onnx/audio-tagging/apk.html)| It shows how to use audio tagging.|
|[EdgevoxOnnxAudioTaggingWearOS](./EdgevoxOnnxAudioTagging)|[URL](https://k2-fsa.github.io/sherpa/onnx/audio-tagging/apk-wearos.html)| It shows how to use audio tagging on WearOS.|
|[EdgevoxOnnxSimulateStreamingAsr](./EdgevoxOnnxSimulateStreamingAsr)|| It shows how to use a non-streaming ASR model for streaming speech recognition.|
|[EdgevoxOnnxSimulateStreamingAsrWearOs](./EdgevoxOnnxSimulateStreamingAsrWearOs)|| It shows how to use a non-streaming ASR model for streaming speech recognition with WearOS.|
